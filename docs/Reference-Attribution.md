# FinderHover reference

Hoover's implementation studied [KoukeNeko/FinderHover](https://github.com/KoukeNeko/FinderHover), revision `76d73b97b26b7b5791c5c1cf501de437bc214ff4`, especially its Accessibility-based Finder item detection, hover lifecycle, and metadata categories.

FinderHover is distributed under the MIT license. Its [license notice](https://github.com/KoukeNeko/FinderHover/blob/main/LICENSE) belongs to the reference project. Hoover's source was reimplemented rather than copied from FinderHover; no reference application or source is bundled in Hoover.

The reference checkout used during development is kept outside Hoover's checkout and is not a shipped app component. If reference source is later copied into Hoover, retain FinderHover's copyright and MIT license notices with that copied source.
